# Jeu : Détruire les Pommes dans l'Espace

Un jeu où vous cliquez sur des pommes (planètes) dans l'espace pour les détruire, gagner de l'XP et monter de niveau pour débloquer de nouvelles armes. La difficulté augmente avec le niveau.

## Comment jouer

- Utilisez les flèches gauche/droite pour déplacer le vaisseau.
- Appuyez sur espace pour tirer.
- Détruisez les pommes qui tombent du haut pour gagner des points et de l'XP.
- Plusieurs types de pommes plus difficiles ont été ajoutés : normales, solides, rapides, armées, grosses et boss.
- Le mode Sniper inflige plus de dégâts.
- Les balles peuvent aller sur les côtés et rebondir sur les murs.
- Vos vies sont affichées en cœurs, et chaque pomme qui atteint le bas vous coûte une vie.
- Un compteur de temps suit la durée de la partie.
- Le vaisseau change automatiquement avec les niveaux, et chaque type de vaisseau tire différemment.
- Avant chaque niveau, un boss spécial arrive.
- Des effets sonores ont été ajoutés pour tirer, toucher les ennemis et vaincre un boss.
- Appuyez sur Entrée ou sur le bouton "Commencer" pour lancer le jeu.
- Perdez si toutes vos vies sont perdues.

## Installation et exécution

1. Lancez le serveur : `python3 -m http.server 8000`
2. Ouvrez `http://localhost:8000` dans votre navigateur.
